단어 목록 붙여 넣기

한 줄에 하나씩. 뜻을 같이 적으려면 단어 - 뜻, 단어(탭)뜻, 단어,뜻 중 아무 꼴이나 됩니다. 뜻을 비우면 Claude 가 채웁니다(40개씩, 1분 안팎).

논문에서 담기

읽기 화면에서 모르는 말을 드래그하고 단어를 누르면 뜻·그 논문의 예문(영어와 번역)·출처가 자동으로 붙어 여기에 쌓입니다. 같은 단어를 다른 논문에서 또 담으면 예문만 더해집니다(최대 5개).
간격 반복은 Anki 가 합니다. 여기서는 방금 담은 것을 훑어보고 아는 것만 표시합니다.

Anki 파일 만들기

Anki 에서 가져오는 법

  1. Anki 를 열고 위쪽 파일 → 가져오기에서 방금 만든 .txt 파일을 고릅니다.
  2. 간단 방식이면 그대로 가져오기를 누르면 됩니다. 덱·탭 구분·HTML 설정이 파일 안에 적혀 있어 Anki 가 알아서 맞춥니다.
  3. 자세히 방식이면 처음 한 번만 노트 유형을 만듭니다. 도구 → 노트 유형 관리 → 추가 → Basic 복제로 Athenaeum 단어를 만들고, 칸을 단어 · 뜻 · 영어설명 · 예문 · 예문번역 · 출처 여섯 개로 맞춥니다.
  4. 같은 파일을 또 가져와도 첫 칸(단어)이 같으면 Anki 가 덮어씁니다. 단어가 늘 때마다 다시 내보내 가져오면 됩니다.
  5. 폰에서 보려면 Anki 에서 동기화를 누르고 AnkiWeb 계정으로 로그인합니다. 안드로이드는 AnkiDroid(무료), 아이폰은 AnkiMobile(유료) 또는 폰 브라우저로 ankiweb.net에 접속하면 됩니다.
