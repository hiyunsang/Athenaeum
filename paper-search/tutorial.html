사용법

Athenaeum — 내 서재로 논문을 모으고, 읽고, 공부하고, 쓰는 작업대

모든 것이 이 컴퓨터 안에서 돕니다. 논문 PDF·요약·번역·공부·원고는 전부 이 폴더에 저장되고, Claude 는 요약·번역·공부·원고의 글을 쓸 때 Claude Code 로 부릅니다(내 Claude 구독 사용량, API 키 없음). 화면마다 어디가 무엇이고 어떻게 쓰는지를 아래 그림에 번호로 적었습니다. 홈 위쪽 「도움말」 로 언제든 다시 엽니다.

① 모으기다운로드 폴더에 논문 PDF 가 들어오면 알아서 이름을 바꿔 보관홈 → 수집
② 찾기내 서재는 라벨·본문으로, 세상의 논문은 말로 적어 탐색홈 검색 · 논문 탐색
③ 읽기요약과 문장 단위 전문 번역, 드래그 → 원문·메모·질문·단어요약 보기 · 번역 보기
④ 공부주제 하나를 내 서재의 논문만으로 교과서 한 장으로공부
⑤ 쓰기근거 카드 → 개요 → 초안 → 검토 → 영문 → 워드, 심사 의견까지원고

처음 시작: ZIP 을 풀고 「Athenaeum 설치.bat」 → Claude Code 설치·로그인 확인 → 바탕화면 아이콘. 그다음 홈의 「수집」 에서 감시 폴더(기본: 내 다운로드)를 확인하고, 논문이 열 편쯤 모이면 홈이 권하는 대로 「라벨 체계 설정」 에서 내 분야의 체계를 Claude 에게 받아 적용하세요.

데이터는 어디에

프로그램 폴더 안에 모두 있습니다. 폴더를 통째로 옮기거나 복사해도 됩니다.

Claude 호출은 모두 Claude Code 를 거칩니다. 홈에 「Claude Code 가 설치되어 있지 않습니다」 가 뜨면 설치·로그인한 뒤 그대로 두면 저절로 사라집니다. 긴 작업(공부 20편: 30~40분, 번역 5~10분)은 창을 닫아도 서버가 계속 하고, 다시 열면 결과가 있습니다.
