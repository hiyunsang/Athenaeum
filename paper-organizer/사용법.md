## 뭘 하는 프로그램인가?

다운로드 폴더(`C:\Users\PC1\Downloads`)를 계속 지켜보다가 **새 PDF가 생기면**:

1. PDF 안에서 DOI(논문 고유번호)를 찾고
2. Crossref(무료 논문 정보 사이트)에서 제목·저자·연도·저널을 조회한 뒤
3. `연도_저널약어_저자_제목.pdf` 형식으로 이름을 바꿔서
4. `C:\Users\PC1\Documents\MAENG_paper\논문모음` 폴더로 옮깁니다.

예: `1-s2.0-S0141635913000937-main.pdf`
→ `2013_PRECIS ENG_Sugihara_Crater and flank wear resistance of cutting tools having micro textured surfaces.pdf`

저널 약어는 직접 정한 것(IJMTM, JMPT, JMP, AMT, Trib, IJMS, ATE)이 우선이고,
목록에 없는 저널은 이니셜 방식(예: Journal of Manufacturing Science and Engineering → JMSE)으로
자동 생성됩니다. 한 단어짜리 저널은 그대로 씁니다 (Wear → WEAR).

## 주제 폴더 (바탕화면 논문주제)

바탕화면 `MAENG\논문주제` 트리에는 이제 **바로가기(.lnk)만** 들어 있고,
진짜 PDF는 전부 `MAENG_paper\논문모음` 한 곳에 있습니다.

- 바로가기를 더블클릭하면 진짜 파일이 열립니다. 어디서 열어도 같은 파일이라
  메모/형광펜이 한 곳에 모입니다.
- 논문을 주제로 분류하고 싶으면: `MAENG_paper`에서 원하는 주제 폴더로
  **그냥 복사해 넣으세요.** 몇 초 안에 자동으로 바로가기로 바뀝니다.
  여러 주제에 넣어도 됩니다 (실체는 하나).
- 다른 컴퓨터/USB로 가져갈 땐 바로가기가 아니라 `MAENG_paper`의 진짜 파일을 가져가세요.

## 논문 검색 프로그램 (라벨 교집합 검색)

`Documents\MAENG_paper\paper-search\논문검색_실행.bat` 더블클릭 → 브라우저에 검색 화면이 열립니다.

- 왼쪽 라벨을 누를수록 교집합으로 좁혀집니다: [BUE] → [BUE]+[In-situ] → ...
- 라벨 옆 숫자는 현재 결과 기준으로 다시 계산됩니다 (0이면 회색)
- 논문 클릭 = PDF 열기, "라벨 편집" = 라벨 붙이기/떼기
- 라벨은 제목·저자 키워드·본문 빈도 기준으로 **자동 확정**됩니다 (전체 제목도 Crossref에서 자동 수집)
- 노란 점선(?)은 애매해서 남겨둔 소수의 제안 - 클릭하면 확정, ✕로 제거(다시 안 올라옴)
- 위쪽 "본문 검색"은 PDF 내용에서 단어를 찾는 것 (라벨과 별개, 조합 가능)
- 논문마다 **[요약] [번역]** 버튼: 처음 누르면 AI가 생성(요약 ~1분, 번역 3~10분),
  그 후로는 즉시 열림. Claude 구독 사용량을 쓰며 별도 결제는 없음.
  결과 파일은 `MAENG_paper\번역\` 폴더에 저장됨.
  버튼이 "요약 생성중 2분"이면 진행 중(새로고침해도 유지), "요약 실패 ⚠"면 마우스를 올려 이유 확인 후 클릭해 재시도.
  요약·번역은 동시에 2개까지 처리되고 나머지는 "대기중"으로 줄을 섭니다.
- **읽기 화면** (요약/번역 보기): 왼쪽 Claude(질문·메모) · 가운데 본문(요약↔전문번역 탭) · 오른쪽 PDF.
  본문 문장을 드래그하면 툴바: 📍 PDF에서 찾기(원문 위치 형광펜) · 🔁 대조(요약↔번역 같은 부분) · 📝 메모 · 🤖 질문(프리셋: 쉽게 설명/왜 중요/용어 뜻).
  메모·질문한 구절은 본문에 형광펜+📝🤖 배지로 남고(배지 클릭 → 패널 항목), 패널의 "▸ 위치"로 본문 위치로 이동.
  "Fig. 3", "Table 2" 글자를 클릭하면 PDF의 그 캡션이 화면 아래쪽에 오게 이동(그림이 보임). 캡션 한국어 번역은 PDF 캡션 아래 노란 박스로.
  PDF 도구: − / + 확대, 🔍 영역 확대(켜고 그림 위를 드래그 → 크게 팝업). 목차는 링크 목록으로(클릭 → 해당 절), 약어·기호표는 표로 자동 정리.
  메모·질문답변은 `MAENG_paper\메모\`에, 캡션 번역은 `MAENG_paper\번역\*.캡션.json`에 저장.
  요약은 논문의 실제 목차를 따라 소단원별로 압축 번역되고(리뷰 논문은 길어짐), 전문번역은 구간별로 나눠 생성됩니다.
  결과가 이상하면 위쪽 **↻ 다시 생성**으로 새로 만들 수 있습니다 (예전 방식으로 만든 것도 이걸로 교체).
  ※ 처음 쓰기 전에 한 번만: 터미널에서 `claude` 입력 → `/login` → 브라우저 로그인
- 라벨 데이터는 `paper-search\tags.json`, 라벨 목록은 `labels.json`

`논문모음\_중복사본\` — 내용이 완전히 같아서 치워둔 중복 PDF (지워도 무방)

**논문이 아닌 PDF(견적서, 강의자료 등)는 절대 건드리지 않습니다** (DOI가 없으면 무시).
잘못 집는 걸 막기 위해, 찾은 DOI의 논문 제목이 실제 PDF 첫 페이지에 있는지도 대조합니다.

## 자동 실행

시작프로그램에 등록되어 있어서 **컴퓨터를 켜면 자동으로 백그라운드에서 돌아갑니다.**
(창이 안 보이는 게 정상입니다)

- 잘 돌고 있는지 확인: 이 폴더의 `정리기록.txt` 열어보기 (모든 처리 내역이 기록됨)
- 눈으로 직접 보면서 돌리기: `수동실행_창보임.bat` 더블클릭
- 끄기: 작업 관리자에서 `pythonw.exe` 종료
- 다시 켜기: `background_run.vbs` 더블클릭 (또는 재부팅)
- 자동 실행 해제: `Win+R` → `shell:startup` 입력 → `paper-organizer.vbs` 삭제

## 설정 바꾸기 (config.json)

`config.json`을 메모장으로 열어서 수정하고 저장하면 **재시작 없이 바로 반영**됩니다.

- `"논문폴더"`: 정리된 논문을 모을 위치 (경로의 `\`는 `\\`로 두 번 써야 함)
- `"저널약어"`: 저널 이름 → 약어 목록. 여기 없는 저널은 약어를 자동 생성하는데,
  마음에 안 들면 이 목록에 한 줄 추가하면 됩니다. 예:
  ```
  "Wear": "Wear",
  "CIRP Annals": "CIRP"
  ```

## 한계 (알아둘 것)

- 스캔본(글자 인식 안 되는 옛날 논문 PDF)은 DOI를 못 읽어서 그대로 둡니다.
- DOI가 본문에 없는 일부 학회 논문도 그대로 둡니다.
- 그대로 남은 논문은 직접 이름을 바꿔서 논문 폴더로 옮기면 됩니다.
- 파일을 지우는 일은 절대 없고, 이동/이름변경만 하며 전부 `정리기록.txt`에 남습니다.
